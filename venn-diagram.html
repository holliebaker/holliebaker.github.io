Venn and Euler diagrams with venn.js!

https://github.com/benfred/venn.js/

Define your sets as an array of JSON objects with name and size, then press the button (see example below).

The programmer was lazy -- if no diagram appears, please check the console for unhandled errors.


[ {"sets": ["A"], "size": 12},
  {"sets": ["B"], "size": 12},
  {"sets": ["A","B"], "size": 2}
]
