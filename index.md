# Associate Lecturer, Software Developer, Braillist.

I'm an [associate lecturer](https://www.bathspa.ac.uk/our-people/hollie-baker/) in Computer Science and Creative Computing at [Bath Spa Uni(https://www.bathspa.ac.uk/). 

I also work with [Bristol Braille Technology CIC]https://bristolbraille.org) developing software for their [Canute Scientific multi-line Braille workstation](https://canute-scientific.bristolbraille.org/). My current project aims to improve access to mathematics through Braille. 
As a Braille reader, I'm excited to work on Bristol Braille's open source projects which improve access to STEM subjects for blind people, and allow them to collaborate with sighted colleagues on an equal footing.

I've also produced some demonstration and promotional videos for the Canute, as well as exhibiting with Bristol Braille at sight loss events, most recently [Sight Village Central](https://www.qac.ac.uk/exhibitions/sight-village-events-2026--dates--venues/1080.htm), and demonstrated how the Canute can be used in maths and computer science at [New College Worcester](https://ncw.co.uk). 

## Projects.

- [Console Graph Theory](https://gitlab.com/holliebaker/console-graph-theory): born from a [transport map application for the Canute](https://www.youtube.com/watch?v=eyMrDcISekU) and a desire for Braille graphs for a lecture on Monday, I spent a weekend adapting the [tactile transport maps](https://gitlab.com/Bristol-Braille/console-condensed-cartographs) to show [GraphViz](https://graphviz.org/) files. I had great fun adding (oddly satisfying) edge scrolling, neighbour and connected component filters, and the ability to annotate and edit the graph, saving it back to GraphViz format. 

- The Creative Industry Challenge students at BSU took the graph viewer and transformed it into an interactive fiction creator and viewer. Aftor all, in computer science, anything can be a graph if you look at it the right way. The [Story Tree](https://gitlab.com/Bristol-Braille/console-story-tree) lets you play stories, containing mini games, on the Canute, as well as work with the story's tree structure in the graph viewer, and export to twine. 

- [twine2canutelib](https://gitlab.com/Bristol-Braille/twine2canutelib): is a rudimentary Twee viewer that lets you play through a Twine story using the Canute menus. Right now it only supports links, no scripts, although I could be tempted to add to it if I find the time. 

- [Multi-line Orca](https://gitlab.com/Bristol-Braille/orca): a fork of the Orca Screenreader for Linux which implements multi-line Braille support for the Canute. A friend hacked a proof of concept in a day, and I ran with it. 

- The same friend modified [the Canute BRLTTY driver](https://gitlab.com/holliebaker/brltty) to have it update from the cursor outwards as opposed to from the top down. I think it's the best thing ever, and polished it off by adding a config option and a runtime parameter so that modes can be switched to suit the application.

- [Console Chess](https://gitlab.com/holliebaker/console-chess): a tactile chess game for the Canute --- just a fun project for learning Curses and trying out multi-line Braille development, but Bristol Braille liked it, and now it's on the Launcher Menu!

- [Escapepod](https://github.com/y20k/escapepod): I labelled some buttons in this app, which I still enjoy using today. 

Past projects that I've let go a bit stale:

- [BusStopNotification](https://github.com/holliebaker/BusStopNotification): a react native app which calls the [bustimes.org](bustimes.org) api and shows live tracking information for specific buses. The goal was to have it notify you when your bus was approaching so you could start waving madly at any large-sounding vehicles, but PhD corrections happened, and I never got around to it. 

- [DeepSpeechTrainer](https://github.com/holliebaker/deep-speech-trainer): a react native app (I was working at Mayden and emmersed in web technologies at the time) for submitting voice snippets to be used to customise a TTS model. 

- [tag-talk](https://github.com/holliebaker/tag-talk): a simple android app that let you write text strings to NFC tags and read them back using text to speech when they were scanned. It seemed like a good idea at the time, and commercial products that do similar things exist ([RNIB Pen Friend](https://shop.rnib.org.uk/products/rnib-penfriend-3-audio-labeller) and [Hable Speech Labels](https://www.iamhable.com/en-om/pages/speechlabel)), but I was too lazy to use it. In the end, I just stuck tiny scraps of Brailled Dymo tape on my spices and now I don't put cumin in my porridge by mistake. .
